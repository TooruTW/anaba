# Design System

日期：2026-10-25　階段：6. 最小設計

風格方向與規則見 [stack.md「畫面風格」](stack.md#畫面風格)。畫面只能使用這裡定義的值；第 7 階段建專案時轉成 Tailwind theme（取代預設值，不是加在預設值上）。元件總覽：`output/prototypes/components.html`。

## 顏色

兩套色系，元件只引用 token 名稱，換色系時元件不用改。回憶的店家頁與回憶清單用「回憶」，其他都用「一般」。

| Token | 用途 | 一般 | 回憶（淺灰燼） |
| --- | --- | --- | --- |
| `bg` | 頁面底色（加霧面顆粒） | `#121110` | `#3a3835` |
| `line` | 框線、分隔線 | `#2c2926` | `#55524e` |
| `text` | 主要文字 | `#efe4d6` | `#efede9` |
| `muted` | 次要文字、欄位名稱 | `#a69a8c` | `#bab6af` |
| `faint` | 最淡的文字：提示、「不清楚」、低調按鈕 | `#8a7f74` | `#aaa59d` |
| `accent` | 強調文字、次要按鈕框 | `#e07a2e` | `#efede9` |
| `fire` | 主要按鈕、選中狀態的底色 | `#e07a2e` | `#e07a2e` |
| `on-fire` | `fire` 上的文字 | `#1a120b` | `#1a120b` |
| `error` | 錯誤訊息、超過字數 | `#e5674f` | `#ff8a73` |

- 所有文字對底色的對比至少 4.5:1（WCAG AA），已逐一計算；新增顏色時要再算一次。
- `fire` 在回憶色系只用在「復活」：整頁唯一的火。
- 地圖顏色（黑色陸地、深灰海、橘色道路）在地圖 style 裡定義，見 [custom-map-prototype.md](custom-map-prototype.md)；篝火用 `output/imagegen/campfire-three-states.svg` 的配色。

## 材質

- 霧面顆粒：SVG `feTurbulence` 雜訊疊在 `bg` 上（`soft-light`），只鋪在頁面底層，元件不各自加。
- 不用陰影、光暈、漸層按鈕。
- 圓角一律 `radius` 4px（按鈕、選項、輸入框、標籤、卡片、確認框、提示）；不用更大的圓角。
- 線條一律 1px。

## 字體

| Token | 字體 | 用途 |
| --- | --- | --- |
| `sans` | Noto Sans TC（Google Fonts，400／700），後備 `system-ui, sans-serif` | 全部文字 |
| `mono` | `ui-monospace, monospace`（系統字體，不載入） | 日期、價位 `$`、評價記號 `III`／`II`／`I` |

Google Fonts 會依 `unicode-range` 切檔，瀏覽器只下載頁面上用到的字；加 `display=swap`，字型載入前先用後備字體。

### 字級

| Token | 大小 | 用途 |
| --- | --- | --- |
| `xs` | 12px | 提示、標籤、字數計數 |
| `sm` | 14px | 日期、區塊小標、低調按鈕、次要說明 |
| `base` | 16px | 內文、按鈕、選項、輸入框（輸入框小於 16px 時 iOS 會自動放大畫面） |
| `lg` | 18px | 頁首標題 |
| `xl` | 24px | 店名 |

粗細只用 400 與 700。

## 間距與尺寸

- 間距只用 4 的倍數：4、8、12、16、20、24、28、36。
- 頁面左右留白 20px。
- 可點擊的元素至少 44×44px；主要按鈕高 48px；評價選項高 52px。

## 元件

| 元件 | 規則 |
| --- | --- |
| 主要按鈕 | `fire` 實心、`on-fire` 字、700；一個畫面最多一個（新增到訪、記下這次到訪、復活） |
| 次要按鈕 | 透明底、`accent` 框與字（在 Google 地圖開啟） |
| 低調按鈕 | 無框、`faint` 字、底線（成為回憶、永久刪除、刪除到訪） |
| 選項 | `line` 框；選中為 `fire` 實心＋`on-fire` 字。單選可再點一次取消（評價除外） |
| 評價選項 | 直排三個，前面以 `mono` 標 `III`／`II`／`I`，不用星星 |
| 輸入框 | 半透明黑底、`line` 框、`base` 字級；字數計數在右下，超過變 `error` |
| 標籤 | `line` 框、`xs`、`muted`（未核對） |
| 清單列 | 上下 12px、底部 `line` 分隔線 |
| 預覽卡 | `bg` 底、上緣 2px `fire` 線、無陰影 |
| 確認框 | `bg` 底、`line` 框，內容文字＋兩個按鈕；危險動作的確認鍵用主要按鈕樣式，取消用次要按鈕 |
| 提示訊息 | 頁面底部浮出，`line` 框、`text` 字，3 秒後消失（已記下這次到訪） |
| 錯誤訊息 | `error` 字、`sm`，出現在送出按鈕上方 |
| 焦點 | 鍵盤焦點一律 2px `fire` 外框、間隔 2px |

招牌時刻（開啟畫面、載入、篝火、送出動畫、空狀態）另外設計，見 stack.md「風格比重」。
